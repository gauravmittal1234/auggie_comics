# Auggie Comics — Story Writer's Guide

Every comic on the site is plain data. A drawing engine turns each panel description into
Marvel-*style* comic art (bold ink lines, halftone dots, starbursts, speed lines), so writers only
describe **what is in the panel** and write the words in **English and Hindi**.

All content must be 100% ORIGINAL. Never mention or imitate any existing comic, cartoon, film,
book or character (no Marvel/DC names, no Scooby, no Chhota Bheem, etc.).

---

## 1. The world of Auggie

**Auggie** is a real, much-loved **yellow Labrador**. These comics turn his life into big adventures.
He lives in the bright Indian city of **Chamakpur** (चमकपुर) with his family.
In the comics, animals can talk and Auggie often lives life *like a human* — he goes on trips,
works on the laptop with Papa, visits cafés, takes selfies, learns things — while still being a
very doggy dog (sniffing, napping, tail-wagging, swimming, rolling in mud, begging for food).

### Super Auggie
When a friend is in trouble, Mumma ties on Auggie's red **Super Cape** with a golden paw badge and he becomes
**Super Auggie**. His powers are dog powers turned up to ten: the **Super Sniffer** nose (can smell a lost
thing across town), **Super Ears** (hears a kitten mew three streets away), a huge **Woof** that can stop
traffic, strong swimming and a very big heart. Super Auggie does NOT fly for real — his "flying" is a giant
superhero leap (pose `fly`). Catchphrase: **"Woof-woof, let's go!" / "भौं-भौं, चलो चलें!"**

## 2. Tone & safety rules (readers are 4–10)

- No real violence, weapons, blood, death, horror or name-calling. Marvel-style *looking* action, but problems are solved by kindness, cleverness, teamwork, a good sniff or a mighty woof.
- **Responsible pet care is always shown correctly:** dogs never eat chocolate, grapes, onions, laddoos or sweets (Auggie may *want* them — then someone explains why not and gives a carrot/apple instead); leash on in traffic; fresh water on hot days; vet visits and vaccines are good; never leave a dog in a hot car; firecrackers scare animals; be gentle with street animals; never tease animals; wild animals are watched from a safe distance with a guide/ranger.
- Every comic ends happily with a gentle **moral**.
- Indian setting and flavour: festivals, food, trains, monsoon, cricket, beaches, hills, villages, real places respectfully.
- Hindi must be natural, simple spoken Hindi in Devanagari — not word-by-word translation.
- Family members are shown lovingly: funny, kind, never mean or embarrassed.

## 3. Age groups

| `age` | Panels | Words per bubble | Style |
|---|---|---|---|
| `"4-6"` | **exactly 6** | max **10** words (EN) | One simple idea, repetition, sounds, feelings, habits, clear moral. Mostly 1 bubble per panel. |
| `"6-10"` | **exactly 8** | max **16** words (EN) | Real plot: problem → twist → clever, kind solution. Up to 2 bubbles per panel. Facts, travel, mysteries. |

Captions (`cap`) max 14 words (4-6) / 20 words (6-10). Hindi can be a bit longer.

## 4. Data format

Each writer produces one JavaScript file:

```js
window.AUGGIE_COMICS = window.AUGGIE_COMICS || [];
window.AUGGIE_COMICS.push(
  { /* comic */ },
  { /* comic */ }
);
```

### Comic object

```js
{
  id: 7,
  age: "4-6",
  category: "home",
  title: { en: "Auggie and the Big Bath", hi: "ऑगी का बड़ा स्नान" },
  blurb: { en: "One-sentence teaser for the cover card.", hi: "..." },
  moral: { en: "Short lesson shown on the last page.", hi: "..." },
  cover: {                          // one dramatic scene for the cover (no words)
    bg: "home",
    chars: [ { id: "auggie", pose: "cheer", mood: "laugh", x: 0.4 }, { id: "mumma", pose: "wave", mood: "happy", x: 0.75, flip: true } ],
    props: [ { id: "bone", x: 0.15 } ],
    fx: { en: "SPLASH!", hi: "छपाक!" }           // optional
  },
  panels: [ /* 6 or 8 panels */ ]
}
```

### Panel object

```js
{
  bg: "bedroom",
  chars: [
    { id: "auggie", pose: "lie", mood: "sleepy", x: 0.35 },
    { id: "papa",   pose: "sit", mood: "laugh",  x: 0.75, flip: true }
  ],
  props: [ { id: "laptop", x: 0.6 } ],
  cap: { en: "Monday morning in Chamakpur...", hi: "चमकपुर में सोमवार की सुबह..." },
  say: [
    { who: 1, en: "Auggie, that's MY pillow!", hi: "ऑगी, वो मेरा तकिया है!" },
    { who: 0, en: "Five more minutes, Papa...", hi: "पापा, बस पाँच मिनट और...", kind: "whisper" }
  ],
  fx: { en: "SNORE!", hi: "खर्र-खर्र!" },
  action: true
}
```

Rules:
- Every panel needs a `cap` or at least one `say`. `who` = index (0,1,2) into that panel's `chars`.
- 0–3 characters per panel, `x` from 0 (left) to 1 (right), keep them ≥ 0.2 apart (0.25 / 0.5 / 0.75). Auggie is a big dog — give him room.
- `flip: true` makes a character face left (default faces right). Make characters face each other when they talk.
- Optional `s` (size 0.5–2) on characters/props; optional `y` (0 top – 1 bottom) on props. Sky props float by default.
- Optional `cape: true` on `auggie` shows his red Super Cape (always shown in pose `fly`). Use it in Super Auggie moments only.
- `kind`: `"say"` (default), `"shout"`, `"think"`, `"whisper"`.
- `fx` + `action: true` for 1–3 big moments per comic. `fx` text max 10 characters, CAPS, ending "!" (WOOF!, SPLASH!, ZOOM!, SNIFF-SNIFF! is too long → SNIFF!). Hindi: भौं-भौं!, छपाक!, ज़ूम!, धड़ाम!, सूँ-सूँ!, वाह!, टन-टन!, फुर्र!, खर्र!
- Auggie should be in most panels.

### Allowed values (anything else fails validation)

**category** — `home`, `habits`, `feelings`, `family`, `friends`, `dogs`, `animals`, `birds`, `festivals`, `travel`, `nature`, `superhero`, `mystery`, `sports`, `science`, `planet`, `space`, `india`

**bg** — `city`, `citynight`, `park`, `garden`, `forest`, `jungle`, `beach`, `ocean`, `underwater`, `space`, `moon`, `mountains`, `snow`, `desert`, `village`, `farm`, `school`, `home`, `kitchen`, `bedroom`, `lab`, `sky`, `rain`, `volcano`, `cave`, `market`, `festival`, `river`, `playground`, `action`, `station`, `airport`, `wedding`, `cafe`, `vet`
(`river` also works as a lake; `lab` = Professor Gadbad's workshop; `station` = railway platform with a train; `wedding` = grand lit-up wedding hall; `vet` = animal clinic; `action` = pure comic colour burst for big hero moments.)

**chars** — `auggie`, `papa`, `mumma`, `mausi`, `nanu`, `dadi`, `rohan`, `anaya`, `kabir`, `zoya`, `moti`, `pinku`, `snowy`, `chiku`, `bholu`, `gadbad`, `kichdu`, `garaj`, `zibbo`, `cat`, `parrot`, `monkey`, `cow`, `rabbit`, `turtle`, `fish`, `frog`, `owl`, `lion`, `penguin`, `dolphin`, `peacock`, `camel`, `goat`, `duck`, `pigeon`, `squirrel`, `crab`, `tiger`, `deer`, `horse`

**pose** — `stand`, `wave`, `run`, `fly`, `cheer`, `point`, `think`, `sit`, `blast`, `lie`
- For dogs: `wave` = gives a paw, `point` = sniffing forward, `think` = head tilt, `cheer` = happy jump, `blast` = big bark, `fly` = Super Auggie leap (cape), `lie` = lying down (with `sleepy` = asleep).
- For people: `blast` = throwing/pushing/pointing a gadget, `lie` shows sitting.

**mood** — `happy`, `sad`, `surprised`, `angry`, `scared`, `determined`, `laugh`, `sleepy`

**props** — `tree`, `palm`, `bush`, `flower`, `rock`, `house`, `ball`, `kite`, `balloon`, `rocket`, `ufo`, `star`, `planet`, `cake`, `gift`, `book`, `trophy`, `umbrella`, `mango`, `apple`, `banana`, `icecream`, `bicycle`, `car`, `bus`, `boat`, `diya`, `toothbrush`, `dustbin`, `sapling`, `map`, `chest`, `telescope`, `gear`, `clock`, `drum`, `rainbow`, `sun`, `cloud`, `puddle`, `bottle`, `crown`, `bulb`, `shell`, `crystal`, `magnet`, `machine`, `bone`, `bowl`, `frisbee`, `suitcase`, `camera`, `laptop`, `plane`, `train`, `tent`, `campfire`, `sandcastle`, `rickshaw`, `hotair`
(`bowl` = dog bowl; `machine` = one of Gadbad's gadgets; `hotair` = hot-air balloon; `rickshaw` = auto-rickshaw; `plane` floats in the sky.)
